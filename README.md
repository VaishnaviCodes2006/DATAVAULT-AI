DataVault AI

Live Demo: https://datavault-ai-1.onrender.com

Organizations increasingly use generative AI to summarize documents, answer employee questions, and automate
business workflows. If confidential information is copied into an unapproved prompt or service, it may be exposed
outside the organization’s intended controls.
DataVault AI is a proposed security gateway placed between users and downstream AI systems. It inspects text and
documents, detects configured sensitive information, classifies the risk, applies policy-based actions, and records a
privacy-conscious audit event. The prototype focuses on a demonstrable workflow: detect → decide → protect →
audit.

Features
Prompt inspection
Policy enforcement
Audit logging
